# Reporting a result

For an Android preview issue, include the app version, phone model and software build, the screen you used, and what you observed. Compare with the [dated handset record](HANDSET-VALIDATION-055.md) for that release. Keep private captures, network identifiers and credentials off public issue reports.

## Compact report template

| Detail | What to record |
| --- | --- |
| Environment | Handset, Android build, app version |
| App behavior | Screen, action, expected result and observed result |
| Evidence | Any relevant redacted message and whether the app restored the prior state |

For the independent OnePlus 13 radio study, see its [report](https://github.com/Bender1011001/oneplus13-internal-wifi-research/blob/main/docs/TECHNICAL-WRITEUP.md) and [research contribution guide](https://github.com/Bender1011001/oneplus13-internal-wifi-research/blob/main/CONTRIBUTING.md).

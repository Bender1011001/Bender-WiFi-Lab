# Corresponding runtime source locations

The APK bundles a Debian 12 ARM64 runtime. Its exact installed binary-to-source mapping is in [runtime-sources.json](../evidence/runtime-sources.json). All 153 binary packages map to 108 source package/version pairs found in official Debian source indices on November 16, 2026.

The table below provides the source descriptor and accompanying source archives next to the application download. Download every listed file for a row to obtain that Debian source package; the JSON records their SHA-256 values and sizes. The `.dsc` describes the source set. Package licenses/copyrights remain in the runtime.

Source locations and checksums were resolved from official HTTPS indices. All 349 source-file URLs returned HTTP 200 to HEAD checks on November 16. This preparation did not download/rebuild all source archives or independently revalidate the index signatures. The original runtime build separately retained signed repository-metadata hashes. These links are external hosting and can move; preserve the exact files and hashes when maintaining the public release.

Privacy review found six embedded private-key-shaped constants in GnuTLS's cryptographic self-tests. Each matched the official, hash-verified upstream source exactly; they are public test fixtures, not user credentials. The [fixture verification](../evidence/runtime-public-fixtures.json) records source location and hashes without reproducing the keys.
